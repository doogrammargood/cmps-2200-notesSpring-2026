# Dynamic Programming Homework

The files contained here help you implement the solutions to Homework 9 to help ensure that you understand the solutions.

Each file contains assertion that check the code when the file is run.

You do not need to submit any code. The code is provided to help you check your understanding and practice coding dynamic programs.

## Files contained

There are 3 files contained here, other than this readme.

### knapsack.py

This file corresponds to Question 1. It contains working code to create the table for the knapsack problem, assuming that all weights and values are positive.
This code was already provided in Lab 6.
We added a function to help you modify accessing the table easily to account for negative values.

### clrs_jobs.py

This file corresponds to Question 2. It contains starter code to solve the problem.

### narrow_grid.py

This file corresponds to Question 3. It contains starter code to find an independent set in a subgraph of a grid graph.
